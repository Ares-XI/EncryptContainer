# EncryptContainer

**EncryptContainer** – это простое и безопасное приложение для асимметричного шифрования сообщений с использованием **ECC-secp256r1** и **AES-256-GCM** (с случайной солью).

---

## Быстрый старт

### 1. Сгенерируйте ключевую пару
- Перейдите в раздел **«Данные ключей»**.
- Нажмите кнопку **«Новая пара ключей»**.
- Дождитесь генерации – пара ключей (публичный и приватный) будет создана и сохранена локально.

### 2. Скопируйте публичный ключ
- В том же разделе нажмите **«Копировать публ. ключ»**.
- Отправьте скопированный публичный ключ вашему оппоненту (тому, кто будет шифровать сообщения для вас).

---

## Шифрование сообщения

1. В главном меню нажмите **«Зашифровать»**.
2. Заполните поля:
   - **Сообщение** – текст, который вы хотите зашифровать.
   - **Публичный ключ оппонента** – вставьте публичный ключ получателя.
3. Нажмите кнопку **«Зашифровать»**.
4. Зашифрованный JSON-текст автоматически скопируется в буфер обмена – отправьте его оппоненту.

> **Совет.** При шифровании сообщение сохраняется в локальном кэше для возможности просмотра отправленных данных.

---

## Расшифровка сообщения

1. Скопируйте полученный зашифрованный JSON-текст.
2. В главном меню нажмите **«Расшифровать»**.
3. Вставьте JSON в поле **«Сообщение»**.
4. Нажмите **«Расшифровать»**.
5. Расшифрованный текст появится в поле **«Расшифровка»**.

---

## Просмотр отправленных сообщений

Если вы забыли, что отправляли оппоненту:

1. Перейдите в раздел **«Данные сообщений»**.
2. Вставьте зашифрованный JSON в поле **«Зашифрованное сообщение»**.
3. Нажмите **«Получить сообщение»**.
4. В поле **«Твоё отправленное»** отобразится исходный текст (извлекается из кэша по JSON-данным).

---

## Экспорт и импорт данных

Вы можете переносить ключи и сообщения между устройствами.

### Экспорт
- В главном меню нажмите **«Экспорт данных»**.
- При желании установите **пароль** для защиты экспортируемого файла.
- Файл будет сохранён локально (или передан через стандартный механизм Android).

### Импорт
- Нажмите **«Импорт данных»**.
- Выберите ранее экспортированный файл.
- Если файл был защищён паролем – введите тот же пароль, что использовался при экспорте.
- Данные будут восстановлены в приложении.

## Безопасность

- **ECC-secp256r1** – для асимметричного шифрования ключей.
- **AES-256-GCM** – для симметричного шифрования сообщений (с автоматической генерацией случайной соли).
- Приватный ключ **никогда не покидает** ваше устройство.
- Пароль для экспорта/импорта не хранится – используется только для шифрования файла с данными.

## Частые вопросы

**Что делать, если я потерял приватный ключ?**  
Никак – без приватного ключа расшифровка невозможна. Всегда делайте резервную копию через **Экспорт**.

**Можно ли использовать один ключ для нескольких оппонентов?**  
Да, но тогда все они смогут шифровать для вас, а вы – расшифровывать. Рекомендуется генерировать отдельную пару для каждого контакта.

**Почему зашифрованный JSON такой большой?**  
Из-за использования ECC-secp256r1 и включения случайной соли – это обеспечивает высокую криптостойкость.
